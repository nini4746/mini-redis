# 0001. 단일 스레드 kqueue 이벤트 루프

- 상태: 대체됨 (0007)
- 날짜: 2026-07-13

## 맥락
여러 클라이언트 연결을 동시에 처리해야 한다. 학습 목표는 이벤트 루프와 소켓 멀티플렉싱의 체감이다.
제약은 C11, 외부 라이브러리 금지, macOS 전용이다.

## 결정
논블로킹 소켓과 kqueue 위에 단일 스레드 이벤트 루프를 둔다. 예외는 RDB 저장용 fork 자식 프로세스뿐이다.
기본 포트는 같은 머신의 진짜 Redis(6379)와 충돌하지 않게 6380으로 한다.

## 대안
- 연결당 스레드, 스레드 풀: 키스페이스에 잠금이 필요해진다.
- libevent 같은 외부 라이브러리: 외부 라이브러리 금지 제약에 걸린다.

## 결과
- 장점: 잠금 없이 다수 연결을 처리한다.
- 단점/감수한 점: macOS에서만 돈다. Linux 지원은 0007에서 poller 인터페이스로 바꿨다.
